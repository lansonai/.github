# 欢迎来到 LansonAI! / Welcome to LansonAI! 👋

## 🚀 关于我们 / About Us

LansonAI 是一个专注于 AI 代码生成和执行的开源项目组织。我们的使命是让 AI 辅助编程变得更加安全、高效和易用。

LansonAI is an open-source project organization focused on AI code generation and execution. Our mission is to make AI-assisted programming safer, more efficient, and easier to use.

## 🌟 核心项目 / Core Projects

### [AI Artifacts - Profile](https://github.com/lansonai/profile)

一个开源的 AI Artifacts 实现，提供强大的 AI 代码生成和执行能力：

An open-source AI Artifacts implementation providing powerful AI code generation and execution capabilities:

- 🤖 **多 AI 模型支持** / Multi-AI Model Support
  - Anthropic Claude Sonnet 3.5
  - OpenAI GPT
  - Google AI
  - Mistral AI
  - Ollama (本地模型 / Local Models)

- 💻 **多语言代码执行** / Multi-Language Code Execution
  - Python (Jupyter Notebook)
  - Next.js Applications
  - Streamlit Applications
  - 更多即将到来... / More coming soon...

- 🔒 **安全隔离环境** / Secure Isolated Environment
  - E2B 云沙箱执行 / E2B Cloud Sandbox Execution
  - 完全隔离的运行环境 / Fully Isolated Runtime
  - 动态依赖安装 / Dynamic Dependency Installation

- 🎨 **现代化技术栈** / Modern Tech Stack
  - Next.js 14 + React 18
  - TypeScript
  - Tailwind CSS
  - Radix UI

## 🛠️ 技术架构 / Technical Architecture

```
用户界面 (Next.js + React)
        ↓
AI SDK (Vercel AI SDK)
        ↓
    ┌───┴───┐
    ↓       ↓
AI 模型   E2B 沙箱
(Claude) (代码执行)
```

## 📚 快速开始 / Quick Start

```bash
# 克隆项目 / Clone the project
git clone https://github.com/lansonai/profile.git

# 安装依赖 / Install dependencies
npm install

# 配置环境变量 / Configure environment variables
cp .env.template .env.local
# 编辑 .env.local 添加你的 API keys

# 启动开发服务器 / Start development server
npm run dev
```
