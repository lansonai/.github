## 关于我们 / About Us

LansonAI 致力于开发先进的 AI 代码生成和执行平台。我们的旗舰项目是一个开源的 AI Artifacts 实现，类似于 Anthropic Claude Artifacts，让用户能够通过自然语言与 AI 交互来生成和运行代码。

LansonAI is dedicated to developing advanced AI code generation and execution platforms. Our flagship project is an open-source AI Artifacts implementation, similar to Anthropic Claude Artifacts, allowing users to generate and run code through natural language interaction with AI.
